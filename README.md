# ♻️ Waste-to-Product Designer - Green Chemistry Edition

Aplikasi web untuk menganalisis limbah dan mengubahnya menjadi produk bernilai tinggi menggunakan **12 Prinsip Kimia Hijau (Green Chemistry Principles)**.

## 🎯 Live Demo

**[Buka Aplikasi di Browser](https://harinnainggolan01-bot.github.io/waste-to-product/)**

Cukup klik link di atas dan langsung gunakan tanpa perlu install!

## 📋 Fitur Utama

✅ **12 Prinsip Kimia Hijau** - Analisis lengkap setiap limbah  
✅ **Penilaian Keamanan** - Tingkat bahaya, toksisitas, risiko kebakaran  
✅ **Dampak Lingkungan** - Jejak karbon, biodegradasi, polusi  
✅ **Interface Interaktif** - 4 Tab untuk eksplorasi detail  
✅ **Responsive Design** - Bekerja di mobile, tablet, desktop  
✅ **Gratis & Open Source** - Tidak perlu biaya apapun

## 📊 12 Prinsip Kimia Hijau yang Dianalisis

1. **Prevention** - Pencegahan limbah sejak awal
2. **Atom Economy** - Ekonomi atom dalam sintesis
3. **Less Hazardous Synthesis** - Sintesis dengan bahan aman
4. **Safer Chemicals** - Desain produk yang lebih aman
5. **Safer Solvents** - Pelarut ramah lingkungan
6. **Energy Efficiency** - Efisiensi energi proses
7. **Renewable Feedstock** - Bahan baku terbarukan
8. **Reduce Derivatives** - Pengurangan derivatif
9. **Catalysis** - Penggunaan katalis
10. **Design for Degradation** - Desain biodegradasi
11. **Real-time Analysis** - Analisis real-time
12. **Accident Prevention** - Keamanan proses

2. Sistem mencari di database

5. User dapat explore 4 tab untuk informasi detail

## 📈 Green Chemistry Score

Score dihitung dari rata-rata 12 prinsip:
- **90-100** = Sangat baik untuk lingkungan
- **70-89** = Baik untuk lingkungan
- **50-69** = Cukup untuk lingkungan
- **<50** = Perlu optimasi
